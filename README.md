# My n8n Workflows Repository

Welcome to my personal repository of **n8n workflows**. This repository contains production-ready automation workflows designed to streamline data processing, input validation, API integration, and automated reporting.

## 🚀 Key Features Included:
- **Form Data Processing & Validation:** Advanced JavaScript handling to parse inputs, validate email structures, and clean up datasets before processing.
- **Dynamic Conditionals:** Multi-stage `IF` nodes and decision-making logic paths (`True/False` branching) to handle successful transactions vs failure protocols.
- **Google Suite Integration:** Automated data logging into Google Sheets (`Append` and `Update Row` actions) with custom status tracking.
- **Automated Communication:** Direct Gmail API triggers to shoot confirmation and cancellation updates dynamically based on the form status.

## 🛠️ Built With
- **n8n** (Node-based Workflow Automation)
- **JavaScript** (For custom code nodes and duration parsing)
- **Google Sheets API & Gmail API**
